Taxonomy VII
The sixteen combat types
Types are mechanical affinities that shape matchups and hook behavior. Creature-family traits such as Mummy, Dragon, Fae, Spider, Aquatic, and Airborne remain separate and can be combined with one primary and one optional secondary type.
Type before multiplier
Each type should first own a recognizable status, operation family, and hook pattern. The effectiveness chart comes after those identities are stable.
Type XVI · Fortune
The desired face
Curse makes a player fear rolling a marked face. Fortune creates the opposite tension: a temporary beneficial symbol is attached to a physical die face, making the player want to roll—and perhaps reroll—that die.

Shared baseline
Fortune generates Favor
Whenever a qualifying Fortune symbol activates, gain one Favor. Fortune cards, creatures, relics, and abilities can spend Favor to manipulate dice, prevent damage, protect cards, cleanse statuses, or improve ability tiers.

Cross-affinity design
How Fortune combines
Fortune becomes a genuine type when every other affinity can manipulate, exploit, accelerate, preserve, steal, or corrupt its Boons.
Creature concepts
Luck Sprite · Fortune
Places one temporary Boon during Income; activation moves it to another die.
Gilded Scarab · Fortune/Swarm
Spreads weak Boons across dice and triggers Jackpot after three different activations.
Fate Weaver · Fortune/Arcane
Moves Boons and Curses between faces to create valuable but dangerous dice.
Fallen Seraph · Fortune/Shadow
Creates powerful Tainted Boons whose activations also generate Debt.
Shrine Golem · Fortune/Stone
Slowly builds durable Fortune symbols that convert Favor into armor.
Fortune Eater · Beast/Shadow
Hunts the most blessed die and consumes any Boon left unused at round end.
Critical tension
Fortune + Curse
Place both overlays on the same valuable face. The result may complete an ultimate, grant Favor, and advance Curse simultaneously. The player is not choosing between a good die and a bad die; they are choosing whether the reward is worth engaging with the danger.

Bestiary VIII
Creature synergy foundations
Each mechanic places persistent state on a shared game object or event stream so unrelated creature families can discover powerful interactions with it.
The design pattern
Attach state to something that travels.
Dice, card instances, damage sources, statuses, links, tags, counters, and recorded events naturally cross multiple battle segments. A creature mechanic becomes highly mixable when other creatures can push those same objects through more hooks.
Strongest prototype foundations
Haunted card instances
Deck · hand · damage reveal · discard · removal
Web links between objects
Dice · cards · statuses · combatants · sources
Bargains and Debt
Immediate power · Income collection · alternative payment
Echoed events
Record · copy · replay · distinguish result from physical action
Encounter-wide Resonance
Shared meters that every creature family can feed or spend
Example mixed encounter
Specter · Spider · Fae
A Specter haunts a card. A Spider webs that card to a die. A Fae bargain improves the die but adds Debt whenever it is rolled. The haunt reacts to the webbed roll, prevention increases the Debt, and every trigger builds encounter Resonance.
Doctrine IX
Engine rules that preserve the magic
Combinatorial interactions stay understandable when the authority makes their timing and provenance explicit.

Record roll provenance.
Offensive, voluntary reroll, forced reroll, defense, status, card, copied result.
Separate event identities.
A copied face is not a physical roll; a face change is not a reroll.
Queue child consequences.
Triggered damage begins after its parent roll batch, never in the middle.
Limit repetitions.
Support once per die, roll batch, resolution, checkpoint, or round.
Persist overlays and history.
Saves, snapshots, AI reconstruction, and replay must agree.
Highest-priority structural work
01
Universal checkpoint dispatcher
for statuses, passives, cards, tokens, actors, and encounter rules.
02
Persistent die instances and overlays
shared by player rolls, status rolls, defenses, and enemy reconstruction.
03
Converge settled and generic resolution
so every proposal can reveal, react, revalidate, and commit consistently.
04
Stable typed timing
using segment, phase, stage, and before/after position instead of scattered strings.

    const reconstruction = [
      ["First roll",[1,4,6,6,6],[0,2,3],1,"Keep one low face and only two sixes. The extra six exceeds requirement capacity."],
      ["Second roll",[1,5],[0],2,"One more low face fills the second of three low-face slots."],

    ];

    let activeSegment = "offensive";
    let activeFilter = "all";
    let rollStep = 0;

    function esc(value) {
      return String(value).replace(/[&<>"']/g, function (char) {
        return {"&":"&amp;","<":"&lt;",">":"&gt;",'"':"&quot;","'":"&#039;"}[char];
      });
    }

    function die(face, cursed, kept) {
      return '<span class="die' + (cursed ? ' is-cursed' : '') + (kept ? ' is-kept' : '') + '" aria-label="Die showing ' + face + (cursed ? ', cursed' : '') + (kept ? ', kept' : '') + '"><strong>' + face + '</strong>' + (cursed ? '<span class="curse-mark" aria-hidden="true">⌁</span>' : '') + '</span>';
    }

    function renderSegments() {
      document.getElementById("segment-tabs").innerHTML = segments.map(function (item) {
        return '<button role="tab" data-segment="' + item[0] + '" aria-selected="' + (item[0] === activeSegment) + '"><span>' + item[1] + '</span>' + esc(item[2]) + '</button>';
      }).join("");
      const segment = segments.find(function (item) { return item[0] === activeSegment; });
      document.getElementById("segment-panel").innerHTML =
        '<div class="segment-title"><div><span>' + segment[1] + ' / Round sequence</span><h3>' + esc(segment[2]) + '</h3><p>' + esc(segment[3]) + '</p></div>' +
        '<div class="live-specimens"><span>Live specimens</span>' + segment[6].map(function (item) { return '<b>' + esc(item) + '</b>'; }).join("") + '</div></div>' +
        '<p class="segment-description">' + esc(segment[4]) + '</p>' +
        '<ol class="step-line">' + segment[5].map(function (step, index) { return '<li><span>' + (index + 1) + '</span><b>' + esc(step) + '</b></li>'; }).join("") + '</ol>' +
        '<div class="opening"><span>High-value opening</span><p>' + esc(segment[7]) + '</p></div>';
      document.querySelectorAll("[data-segment]").forEach(function (button) {
        button.addEventListener("click", function () { activeSegment = button.dataset.segment; renderSegments(); });
      });
    }

    function renderHooks() {
      document.getElementById("hook-list").innerHTML = hooks.map(function (hook) {
        return '<article class="hook-card" data-state="' + hook[3] + '" data-search="' + esc([hook[1],hook[2],hook[5]].concat(hook[4],hook[6]).join(" ").toLowerCase()) + '">' +
          '<div class="hook-index"><span>' + hook[0] + '</span><b>' + hook[2] + '</b></div>' +
          '<div class="hook-copy"><div class="hook-title"><h3>' + esc(hook[1]) + '</h3><span class="state-pill state-' + hook[3] + '">' + states[hook[3]].label + '</span></div>' +
          '<p>' + esc(hook[5]) + '</p><div class="tag-row">' + hook[4].map(function (tag) { return '<span>' + esc(tag) + '</span>'; }).join("") + '</div></div>' +
          '<ul>' + hook[6].map(function (example) { return '<li>' + esc(example) + '</li>'; }).join("") + '</ul></article>';
      }).join("");
      applyHookFilters();
    }

    function applyHookFilters() {
      const query = document.getElementById("hook-search").value.trim().toLowerCase();
      let visible = 0;
      document.querySelectorAll(".hook-card").forEach(function (card) {
        const match = (activeFilter === "all" || card.dataset.state === activeFilter) && (!query || card.dataset.search.includes(query));
        card.hidden = !match;
        if (match) visible += 1;
      });
      document.getElementById("result-count").textContent = "Showing " + visible + " of " + hooks.length + " recorded checkpoints";
      document.getElementById("empty-state").hidden = visible !== 0;
    }

    function renderReconstruction() {
      const step = reconstruction[rollStep];
      document.getElementById("roll-step-label").textContent = "Roll " + (rollStep + 1) + " of 3";
      document.getElementById("previous-roll").disabled = rollStep === 0;
      document.getElementById("next-roll").disabled = rollStep === 2;
      document.getElementById("current-roll-label").textContent = step[0];
      document.getElementById("current-roll-dice").innerHTML = step[1].map(function (face, index) { return die(face, face === 1, step[2].includes(index)); }).join("");
      document.getElementById("current-roll-note").textContent = step[4];
      const kept = reconstruction.slice(0, rollStep + 1).flatMap(function (item) { return item[1].filter(function (_, index) { return item[2].includes(index); }); });
      document.getElementById("kept-pool").innerHTML = kept.map(function (face) { return die(face, face === 1, true); }).join("");
      document.getElementById("curse-points").innerHTML = [1,2,3].map(function (point) { return '<i class="' + (point <= step[3] ? 'filled' : '') + '">⌁</i>'; }).join("");
      document.getElementById("curse-count").textContent = step[3] + " / 3";
    }

    function renderSynergies() {
      document.getElementById("synergy-grid").innerHTML = synergies.map(function (item, index) {
        return '<details' + (index === 0 ? ' open' : '') + '><summary><span>' + String(index + 1).padStart(2,"0") + '</span><div><h3>' + esc(item[0]) + '</h3><p>' + item[1].map(esc).join(" · ") + '</p></div><b aria-hidden="true">+</b></summary>' +
          '<div class="synergy-body"><p>' + esc(item[2]) + '</p><div>' + item[1].map(function (tag) { return '<span>' + esc(tag) + '</span>'; }).join("") + '</div></div></details>';
      }).join("");
    }

          '<h3>' + esc(type[1]) + '</h3><p>' + esc(type[2]) + '</p>' +
          '<small>Signature mechanic</small><strong>' + esc(type[3]) + '</strong></article>';
      }).join("");
      document.getElementById("fortune-type-grid").innerHTML = fortunePairings.map(function (pairing) {
        return '<article><span>' + esc(pairing[0]) + '</span><p>' + esc(pairing[1]) + '</p></article>';
      }).join("");
    }

    function renderCreatureIdeas() {
      document.getElementById("creature-grid").innerHTML = creatureIdeas.map(function (idea, index) {
        return '<details' + (index === 0 ? ' open' : '') + '>' +
          '<summary><span>' + String(index + 1).padStart(2,"0") + '</span><div><small>' + esc(idea.family) + '</small><h3>' + esc(idea.mechanic) + '</h3><p>' + esc(idea.object) + '</p></div><b aria-hidden="true">+</b></summary>' +
          '<div class="creature-body"><p class="creature-premise">' + esc(idea.premise) + '</p>' +
          '<div class="creature-columns"><div><span>Hooks touched</span><ul>' + idea.hooks.map(function (hook) { return '<li><code>' + esc(hook) + '</code></li>'; }).join("") + '</ul></div>' +
          '<div><span>Mixing patterns</span><ul>' + idea.partners.map(function (partner) { return '<li>' + esc(partner) + '</li>'; }).join("") + '</ul></div></div>' +
          '<blockquote>' + esc(idea.example) + '</blockquote></div></details>';
      }).join("");
    }

    document.getElementById("hook-search").addEventListener("input", applyHookFilters);
    document.querySelectorAll("[data-filter]").forEach(function (button) {

        document.querySelectorAll("[data-filter]").forEach(function (item) { item.classList.toggle("active", item === button); });
        applyHookFilters();
