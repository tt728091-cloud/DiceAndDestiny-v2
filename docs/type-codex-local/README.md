# Local Combat Type Codex

Open `index.html` in your browser. It is static HTML and works at its existing local-file URL without a server. All 16 type tabs now contain dossiers. Curse and Venom are preserved references; the other 14 are review-only proposals.

Each new type includes a five-die face map, four signature status definitions, each with a purpose and example, six abilities, 24 cards, two worked build sequences, cross-type interactions, counterplay, and shared timing/edge-case rules. Initial ability qualification odds enumerate all 7,776 unmodified five-D6 outcomes and do not claim optimal-reroll success rates.

Review controls are under each new type’s **Synergies & review** tab. Notes and checkmarks stay in that browser’s local storage where available. **Export all review notes** downloads a JSON copy. A reviewed checkmark does not authorize or perform implementation. Card search is scoped to the selected type.

Current pending dossiers are **revision 2**. Read [the status revision note](review/status-rework-v2.md) for the mechanical changes, wording decisions and reference patterns.

## Editing and regeneration

Edit the relevant `drafts/<type>.json` for a new type, or `shared-rules.json` for shared draft rules. Then run from the repository root:

```sh
python3 docs/type-codex-local/build_dossiers.py
python3 docs/type-codex-local/validate_dossiers.py
```

The generator replaces only the marked new-dossier block and the interaction index rows. It does not replace the existing Curse or Venom panels. Their baseline snippets and SHA-256 hashes are in `review/`; validation requires them to remain byte-for-byte unchanged. An intentional later user-requested revision to either reference should update its baseline and explain the decision in the Venom handoff or a corresponding Curse note.

The JSON is design data, **not executable game content**. No files in `content/battle_v1`, `content/venom_v1`, client code, server mechanics or trained models are generated by this tool. New characters require separate authorization, content implementation and gameplay tests.
