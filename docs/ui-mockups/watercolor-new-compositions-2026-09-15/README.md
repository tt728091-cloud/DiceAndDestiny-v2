## Shared battle state

Round 4, offensive planning. Venom 7/24 health, 1 energy, Bleed 2. Blade Warden 12/20 health, 5 energy, Poison 2. Four player abilities with visible symbol recipes; five cards with costs 0, 0, 1, 2, 2. Roll five dice, three rolls left, skip and utility controls. No pile counters.

These are static art-direction explorations, not implemented screens. Small generated UI details need cleanup in implementation: health gauges are not consistently proportional; some Needlefang alternatives use whitespace rather than slashes. Salt-flat Mirage has an extraneous 1 inside each energy icon; the correct energy values are the adjacent 1 and 5. Two targeted image edits failed to remove those digits, so the sharper original was retained.
