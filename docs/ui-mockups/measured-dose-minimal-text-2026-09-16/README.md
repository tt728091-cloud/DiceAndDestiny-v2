# Measured Dose — minimal effect text

Five card mockups using the user-supplied image as reference. All retain title Measured Dose, energy cost 2 and the short effect Gain two catalysts. Created with built-in image generation. Static visual concepts; game code and card rules were not changed.

## Variants

1. [Parchment footer](01-parchment-footer.png)
2. [Dark caption band](02-dark-caption-band.png)
3. [Effect beneath title](03-effect-under-title.png)
4. [Inset effect plaque](04-inset-effect-plaque.png)
5. [Two-line summary](05-two-line-summary.png)

Recommendation: parchment footer for a clear consistent effect area. Effect beneath title is useful if only card tops remain visible in a fanned hand. Keep expanded rules and keyword definitions available on hover/inspect; show the one-sentence action on the card. Exact typography should be verified at the actual in-game card size before implementation.
