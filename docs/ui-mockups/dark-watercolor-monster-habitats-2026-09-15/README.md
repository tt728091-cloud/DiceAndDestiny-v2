# Dark watercolor monster habitats

Ten monster-and-terrain concepts retaining the approved Venom character and battle UI layout. Generated with the built-in image-generation tool, one reference-image edit per pairing. Each changes the monster, complete landscape, light, palette and supporting card-art details. No face-shaped terrain. No game implementation changed.

## Shared layout and sample state

Five dice above Roll/Skip at left; abilities stacked beneath; Venom clear of the controls; five cards bottom-center; utilities bottom-right; health and phases at top. Venom: 7/24, energy 1, Bleed 2. Every enemy uses the same illustrative 12/20, energy 5, Poison 2 comparison state; these are not enemy balance proposals. Core ability recipes and card names/costs retained. These are static visual concepts, and exact glyph/health presentation should come from the game's UI during implementation.
