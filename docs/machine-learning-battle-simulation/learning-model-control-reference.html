The learning loop in one picture

At every learner decision, PPO receives the visible state, candidate actions, and a mask. It samples an action during training. The battle eventually produces a terminal reward, and PPO adjusts both the actor and critic.

1 · Observation

Visible health, resources, dice, abilities, requirements, candidates, and other encoded state.

→

2 · Actor + critic

The actor assigns action probabilities. The critic estimates expected eventual reward from the current state.

→

3 · Outcome and update

The terminal reward is propagated backward. Better-than-expected actions become more likely; worse actions become less likely.

What PPO sees

18,944 floats: 2,560 base game-state values plus 128 candidate actions with 128 values each.

What PPO may choose

Up to 128 exact authority commands. Padding and non-progressing commands are masked out.

What PPO optimizes

A terminal winner-health reward: outcome ±0.5 plus up to ±1.0 from the actual winner’s health fraction.

The five largest levers: what the model sees, what actions it can consider, what reward it receives, which opponents generate experience, and which checkpoint-selection rule decides what survives.

Group 1 · Current-campaign branches

Resume-safe training controls

These can technically branch from an existing checkpoint while preserving weights and optimizer. “Resume-safe” does not mean statistically clean: changing one creates a new experimental branch and can still destabilize training.

Learning rate and scheduleControls how strongly gradients move parameters during each optimizer update.›
CP193: constant 0.0003Branch-safe

Weights do not become “heavier” or automatically resist change as training continues. Later updates may become smaller because gradients shrink near a solution, Adam’s stored history changes the effective step, or PPO clipping rejects more movement—but a constant learning rate can continue moving or wandering indefinitely.

A decreasing schedule deliberately makes later checkpoints more conservative. Lowering learning rate also scales entropy and critic updates; it does not selectively reduce exploration.

PPO epochsHow many times PPO reuses each collected rollout.›
CP193: 8 epochsBranch-safe

More epochs extract more learning from the same games, but increase the chance of overfitting that rollout or moving the policy too far. Samples already beyond PPO’s useful clip boundary may stop contributing actor gradient in that direction, while unclipped samples, value loss, and entropy still update.

Clip rangeLimits the incentive to change the probability of each sampled action—not individual weights.›
CP193: 0.2CP193 clipped fraction: 10.02%

Clip range is not a weight-A/weight-B budget. It acts on the probability ratio new action probability / old action probability for each sampled state and action.

Old probability 40% · positive advantage · clip 0.2 → that sample stops rewarding an increase beyond roughly 48% (40% × 1.2).
Old probability 40% · negative advantage · clip 0.2 → that sample stops rewarding a decrease below roughly 32% (40% × 0.8).

It is a soft objective guard. Other samples share the same weights, so the final probability can still move beyond the nominal boundary.

Target KLAn update-level emergency brake when average policy movement becomes too large.›
CP193: disabledObserved approximate KL: 0.02036

Clip range acts locally on sampled action ratios. Target KL measures broader average divergence between the old and new action distributions. If the threshold is exceeded, PPO stops the remaining epochs for that update.

Entropy coefficientPays the policy to retain action variety instead of collapsing too early.›
CP193: 0.01 constant

Higher entropy encourages exploration; lower entropy encourages commitment. Entropy can naturally fall when evidence for particular actions overwhelms the bonus, but the coefficient does not currently decay automatically.

An entropy schedule could intentionally explore more early and less late. A learning-rate schedule shrinks every loss component together and therefore is not a substitute for a dedicated entropy schedule.

Batch sizeNumber of decisions used in each gradient calculation.›
CP193: 256

CP193 collected 3,072 learner decisions per PPO update: 12 environments × 256 rollout steps. Batch size 256 gives 12 minibatches per epoch and 96 minibatch updates across eight epochs.

We judge batch size using approximate KL, clip fraction, entropy, critic explained variance, stability across seeds, and evaluation improvement. The network does not add parameters as it trains, so batch size does not need to grow automatically. A materially larger architecture may benefit from larger batches.

Rollout sizeHow much fresh experience is collected before PPO updates.›
CP193: 256 per worker

Larger rollouts provide broader, less correlated evidence but make updates less frequent. Rollout size interacts with worker count and batch size; changing any one changes the effective update structure.

GammaHow strongly a final battle result credits decisions made much earlier.›
CP193: 0.995

Gamma is deliberately high because the reward arrives at battle completion. One environment step is one learner action followed by all opponent actions needed to return control to the learner.

Distance from terminal rewardRemaining influence at γ = 0.995
50 learner decisionsAbout 77.8%
100 learner decisionsAbout 60.6%

PPO does not literally label every move after replay. It calculates returns and advantages that estimate whether each decision led to a better result than the critic expected.

GAE lambdaBalances long-range direct evidence against lower-variance critic bootstrapping.›
CP193: 0.95Critic explained variance: 0.845

The combined trace factor is approximately 0.995 × 0.95 = 0.94525. Higher lambda, such as 0.97–0.99, would carry terminal evidence farther backward but would also increase variance.

CP193’s critic metrics show the current combination functions well, not that it is optimal. A higher-lambda family should be tested as a one-variable branch against fixed seed banks.

Critic/value-loss coefficientControls how strongly the critic learns to predict future return.›
CP193: 0.5Value loss: 0.0384

The critic predicts V(state), the expected discounted final reward before the action. If the result is better than expected, the action has positive advantage; if worse, negative advantage. This baseline prevents every action in a winning battle from appearing equally responsible.

CP193’s actor and critic are mostly separate networks, so changing this coefficient chiefly affects critic learning. Explained variance of 0.845 is healthy; there is no current evidence that this should be the first control changed.

Opponent category weightsHow often training draws from global, checkpoint, historical, teacher, or random opponent groups.›

Category weights shape the experience distribution. CP193’s campaign bypassed a mixed pool and used frozen CP38 as the sole PPO opponent.

Historical-opponent selectionWhich old checkpoints remain available and how recency or difficulty affects sampling.›

History can prevent forgetting and exploitation of a single opponent. An uncontrolled flat history can dominate training with thousands of nearly identical checkpoints, so selection and weighting must be explicit.

CurriculumA planned progression from easier or narrower experience to harder, broader experience.›

A curriculum might begin with mechanics teachers or targeted scenarios and later shift to the global champion. It can accelerate early learning but can also bias the final strategy if difficulty changes are poorly timed.

Teacher-opponent frequencyHow often normal PPO episodes use a hand-authored mechanics teacher as the opponent.›

This is different from behavior cloning before PPO. CP193’s continuation used no teacher opponent during PPO and forbade automatic post-PPO teacher correction.

Seat scheduleHow often the learner occupies seat A versus seat B.›
CP193: alternating

Simultaneous planning does not prove mathematical seat identity. Priority, command resolution, reaction ordering, random-stream consumption, and seat-identity inputs can introduce small effects. The CP193 title match recorded 1,400 seat-A wins and 1,374 seat-B wins, close but not identical. Alternation is inexpensive protection against seat specialization.

Group 2 · New model families

Controls that change what the model is

These alter the meaning or shape of inputs, outputs, architecture, or objective. They should normally start a fresh model family rather than reinterpret an existing checkpoint.

Observation featuresThe visible game-state information supplied to PPO at each decision.›
CP193: Observation V2Family changeImportant opportunity

Current inputs include health, resources, dice, rolls remaining, segment, priority, ability requirements and effects, candidate actions, and targets. The model does not receive hidden opponent information or future RNG.

Reroll probability idea

CP193 sees current dice, the subset a candidate would reroll, rolls remaining, and current requirement progress. It does not directly receive the probability that a reroll qualifies an ability. It must learn that from experience.

The mechanics teacher already calculates public one-roll counterfactual outcomes. Safe new candidate features could include probability of qualifying the selected ability, probability any ability qualifies, expected best tier, expected damage/status value, and probability of improvement. These calculations use public die faces and do not leak the next roll.

Implication: adding public reroll probabilities could materially improve sample efficiency, but it changes observation meaning and requires a fresh family.

Status encodingHow active buffs, debuffs, stacks, triggers, and status choices are represented.›
Current V2 is limited

Status encoding is one portion of observation; cards and abilities have separate representations. V2 sees each combatant’s number of active statuses and some generic status effects in candidates, but does not provide a complete structured list of active status identities, stacks, durations, polarity, and triggers.

Abilities are encoded in more detail. Cards are summarized by cost, target, and generic operation categories. Full active-status rows are a strong Observation V3 candidate.

Network width or depthHow much representational capacity the actor and critic have.›
Actor: two 96-unit layersCritic: two 128-unit layers

Width adds more parallel feature combinations and is usually the safer first MLP capacity increase. Depth supports multi-stage composition—for example dice → ability → card modifier → opponent state → final value—but is harder to optimize.

Increase capacity when both training and evaluation plateau while optimization remains healthy. If training becomes strong but evaluation does not, more capacity may worsen overfitting. Controlled comparisons such as 96×2, 128×2, 192×2, and 128×3 are more reliable than guessing.

Actor/critic architectureThe actor chooses actions; the critic predicts how promising the current state is.›
  1. The critic predicts expected discounted terminal reward from the observation.
  2. The battle supplies the eventual reward.
  3. PPO compares calculated return with the critic’s expectation.
  4. The resulting advantage tells the actor whether the sampled action performed better or worse than expected.

The critic does not search future moves or directly judge an action. It learns from prior trajectories and reduces the noise of sparse terminal rewards.

Entity embeddingsLearned compact vectors for mechanically described abilities, cards, statuses, or creatures.›

CP193 does not use a traditional ID embedding table. It uses numeric mechanics and shared candidate layers. A fuller entity encoder would transform cost, requirements, damage, statuses, targeting, and qualification into a compact learned vector.

Gradients cause mechanically similar entities to develop useful similar representations. This reuses learning across content and supports generalization without depending on names.

Variable-length entity encodingProcesses however many entities exist instead of assigning every possibility a permanent slot.›

This is not about the number of opponent types. CP193 uses fixed capacities for a one-on-one battle: 12 abilities, 10 dice, 8 symbols, and 128 candidates. Variable-length encoding would pool or attend over the actual number of abilities, statuses, cards, or creatures.

Action representationHow every exact authority command is described to the actor.›
Actively used by CP193

CP193 does not treat output slot 47 as a permanently named move. The authority generates up to 128 submission-ready commands, and each receives 128 features describing command type, rerolled dice, cards, cost, target, linked ability, requirements, and generic effects.

A shared scoring network evaluates every valid candidate. This mechanics-based representation is central to the model.

Reward definitionThe objective PPO is directly trained to maximize.›
winner-health-v2Terminal only
Win: +0.5 + 1.0 × learner winner-health fraction
Draw: 0
Loss: −0.5 − 1.0 × opponent winner-health fraction

The new reward materially improved champion performance while retaining an essential property: every win is positive and every loss negative.

Additional shaping is risky. Damage can reward pointless aggression, bleed can displace immediate wins, healing can prolong games, and resource rewards can encourage hoarding. Missing observation semantics should be improved before adding more proxy objectives.

Memory/recurrent architectureCarries learned information across decisions when the current observation is not sufficient.›

Memory is not the same as search or “thinking many moves ahead.” Gamma, GAE, and the critic already connect current actions to later outcomes.

Recurrence helps when relevant history is absent from the snapshot: previously played cards, revealed information, opponent tendencies, or past events. If the current state is Markov-complete, recurrence adds complexity without benefit. Observation omissions should be addressed first.

Action pipeline

What options the model actually receives

The real authority creates complete commands. The encoder describes them. The mask removes padding and non-progressing actions. The actor—not the generator—ranks the remaining candidates.

Action-candidate generationCreates every immediately legal, submission-ready command for the acting seat.›

If a strategic command is absent here, PPO can never learn it. Current generation includes reroll subsets, qualified ability/target combinations, playable card/target combinations, reactions, defenses, and passes.

Sharpen Blade case studyThe legal option is complete, but its pre-play semantic description is incomplete.›
Authority behavior correctObservation gap

The authority generates one Sharpen Blade candidate for every owned offensive ability when the card is in hand, affordable, and in the correct window. Playing it on Sword Cut is available.

Before play, PPO sees card cost, target ability, and that the card applies an ability modifier. It does not clearly receive the nested meaning “pair or better adds Bleed,” nor a card-name identity. After the card is played, the modified ability correctly includes the pair requirement and Bleed effect in observation.

This is a plausible reason Sharpen Blade is underused: the move exists, but the actor receives an incomplete explanation of its future value.

128-position action maskA fixed output canvas containing valid candidates plus disabled padding.›

If the authority supplies 37 candidates, positions 0–36 contain exact commands and the remaining positions are padding. The mask disables padding and certain legal-but-non-progressing commands such as provisional keep actions that could loop indefinitely.

The mask is a safety/filter mechanism, not a recommendation score.

Candidate orderingStable canonical placement of commands before the actor scores them.›

The authority does not recommend or rank moves. The actor’s weights determine scores. The shared position-independent candidate scorer reduces dependence on whether a command appears in slot 5 or slot 60.

Input/action capacity failureHard overflow or an impossible nonterminal mask produces a visible error.›

Exceeding action, ability, dice, or symbol limits raises a runtime error. A nonterminal state with no valid candidate also fails. Campaign safety checks record invalid actions, truncations, rejects, leaks, and replay mismatches.

Controls missing from the original list

Starting state, optimization guardrails, and experience generation

Observation scaling and normalizationConverts health, resources, counts, and progress into numerically useful ranges.›

V2 manually normalizes most counts and fractions. Poor scaling can make useful features difficult to learn. This is distinct from advantage normalization.

Hidden-information boundaryControls what the learner is legally allowed to observe.›

Opponent hidden cards, private planning state, and future random results must never enter the observation. Viewer-safe authority snapshots and leak counters enforce this boundary.

Initial weights, checkpoint, and optimizerDetermine what knowledge and momentum exist before the next update.›

A fresh network creates a new family. Continuing CP193 preserves learned strategy. Exact rollback must restore both weights and Adam optimizer state because stored momentum changes later updates.

Random seedControls initialization, environment randomness, opponent sampling, and reproducible trajectories.›

Different seeds can create substantially different models even with identical controls. Seed changes are therefore real experimental branches, not cosmetic reruns.

Behavior-cloning examples and epochsHow much teacher behavior is copied before PPO begins.›

The original setup allowed 5,000 teacher decisions over five imitation epochs. Teacher identity, scenario distribution, example count, and cloning strength shape the entire family’s starting behavior.

Post-PPO correctionWhether teacher cloning is allowed to rewrite a policy after PPO.›
CP193: forbidden

Automatic correction can overwrite strategies discovered through self-play. Any correction should be an isolated challenger that must pass the same gates rather than silently modifying the accepted parent.

Advantage normalizationRescales minibatch advantages to approximately mean zero and standard deviation one.›
Enabled

Normalization prevents one unusually large-return batch from dominating gradients. It is especially useful with terminal rewards and variable battle lengths. The downside is removing absolute advantage-scale differences between batches. With batch size 256 and rewards bounded to ±1.5, enabling it is the safer default.

Gradient clippingLimits the global gradient norm from one minibatch before the optimizer step.›
Maximum norm: 0.5CP193 mean recorded norm: ~0.474

These guardrails operate at different layers:

  • PPO clipping: limits incentive to move sampled action probabilities.
  • Target KL: can stop the remaining update.
  • Gradient clipping: scales an oversized gradient vector while preserving direction.
  • Learning rate: scales application of the resulting update.
  • Adam: adapts movement per parameter using optimizer history.
Value-function clippingOptionally restricts how rapidly critic predictions change.›
Not separately enabled

This is distinct from actor probability clipping. It can stabilize a volatile critic but can also slow correction of wrong value estimates.

Optimizer type and settingsConvert gradients into parameter changes using stored momentum and adaptive scaling.›

Adam’s momentum, variance estimates, epsilon, and learning rate all affect movement. This is why optimizer state must be preserved or rolled back with the checkpoint.

Learner action samplingTraining samples from action probabilities instead of always selecting the top action.›
Example policy: Attack 60% · Reroll 30% · Pass 10%
Training samples in approximately those proportions. Evaluation and the playable game choose Attack because it is the argmax.

PPO records the chosen action’s probability and changes it according to advantage. Entropy resists premature collapse.

Opponent determinismWhether a model opponent samples its policy or always takes its highest-probability action.›

CP193 trained against a sampled version of CP38, not exactly the deployed behavior. Deterministic opponent training would target the version used in evaluation and play, but would expose the learner to a narrower set of opponent lines.

Episode action limitSafety limit on total commands from both combatants in one complete battle.›
One episode = one battleLimit: 1,200 commands

A battle reaching the limit is truncated and does not receive a normal terminal win/loss reward. This has not occurred: zero truncations in 199,391 campaign training episodes and 303,000 checkpoint evaluations. The CP193 title-match maximum was 351 commands.

Training seed distributionDetermines the reproducible random situations the model experiences.›

Seeds control dice, deck ordering and draws, authority randomness, and reproducible transitions—not only dice. Model sampling uses reproducible random streams as well. Adding probability features changes interpretation, not seed distribution. Rare card/status situations are better addressed with curriculum or stratified scenarios than by guessing seed numbers.

Game rules, content, and matchupThe environment’s actual mechanics, distinct from the model’s encoded description of them.›

Rules determine what truly happens; observation determines what PPO knows about it. Sharpen Blade works correctly in the authority while its pre-play value is incompletely encoded. Training only Blade Warden mirrors also teaches a narrower strategy than training across creatures.

Training duration, checkpoints, and workersHow much experience is gathered, how often it is judged, and how many environments contribute.›

More PPO steps create more opportunity to improve or drift. CP193-family intervals requested 50,000 steps and completed 52,224 rollout-aligned steps. Twelve workers created the 3,072-decision update buffer.

Indirect but powerful

Campaign-selection controls

These do not change one PPO gradient. They decide which checkpoint becomes the next parent and therefore strongly influence the eventual model.

Evaluation opponent

Defines what “better” means. Evaluating only against the global champion selects for that matchup.

Game count

More games reduce sampling noise. The recent workflow uses 1,000-game checkpoint gates and explicit 3,000-game title matches.

Seed banks and seat swaps

Fresh, fixed, disjoint seeds and both seat assignments make comparisons reproducible and reduce seat bias.

Evaluation score

Promotion uses wins + 0.5 × draws. PPO’s health-shaped reward is not used as the match score.

Pass threshold

Determines whether a challenger merely beats a family baseline or must exceed the global champion.

Rollback streak

Determines how many consecutive misses are permitted before exact model-and-optimizer restoration.

Promotion rule

Controls when a high-water checkpoint officially replaces the global champion.

Deterministic evaluation

Both policies use highest-probability valid actions, matching the deployed model behavior rather than training-time sampling.

Review conclusions

What the detailed review uncovered

Observation gap

Reroll probabilities are learned indirectly

The mechanics teacher computes public counterfactual odds, but CP193 does not receive those calculations as features.

Observation gap

Active statuses are underencoded

V2 largely exposes status counts and generic effects rather than structured identities, stacks, durations, and triggers.

Card semantics

Sharpen Blade exists but is poorly explained

Every legal target option is generated, yet the pre-play candidate does not clearly expose pair-or-better → Bleed.

Behavior mismatch

Training opponents sample; deployed opponents do not

Training sees a broader stochastic opponent, while evaluation and the game use deterministic argmax behavior.

Healthy

No capacity or truncation issue

Maximum observed candidates and battle length were comfortably below limits, and safety counters remained zero.

Healthy

Current critic and batch metrics are credible

Explained variance 0.845, value loss 0.0384, clip fraction 10.02%, and approximate KL 0.02036 show no obvious failure.

Current ordering of attention: improve missing observation semantics first; then test deterministic opponent behavior and carefully controlled PPO branches; treat additional reward shaping and recurrence as later experiments.
